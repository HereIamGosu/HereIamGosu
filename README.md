## Projects

### AmneziaWG Config Generator

Web UI and HTTP API for generating AmneziaWG / WireGuard client configurations on top of a freshly registered Cloudflare WARP device, with split-tunnelling route presets, DNS presets and CPS obfuscation packets.

<p>
  <a href="https://github.com/HereIamGosu/amnezia-config-gen">
    <img alt="Stars" src="https://img.shields.io/github/stars/HereIamGosu/amnezia-config-gen?style=flat&label=stars">
  </a>
  <a href="https://github.com/HereIamGosu/amnezia-config-gen/actions/workflows/ci.yml">
    <img alt="CI" src="https://github.com/HereIamGosu/amnezia-config-gen/actions/workflows/ci.yml/badge.svg">
  </a>
  <a href="https://github.com/HereIamGosu/amnezia-config-gen/releases">
    <img alt="Release" src="https://img.shields.io/github/v/release/HereIamGosu/amnezia-config-gen">
  </a>
  <a href="https://github.com/HereIamGosu/amnezia-config-gen/blob/main/LICENSE">
    <img alt="License" src="https://img.shields.io/github/license/HereIamGosu/amnezia-config-gen">
  </a>
</p>

**Stack:** JavaScript, Node.js, Docker, nginx, GitHub Actions, GHCR  
**Status:** active open source project, live at awgconfig.com  
**Links:** [repository](https://github.com/HereIamGosu/amnezia-config-gen) · [generator](https://awgconfig.com/) · [English version](https://awgconfig.com/en)

What it does:

- generates `.conf` profiles through a browser UI and API, in Russian and English;
- builds AmneziaWG 2.0 configs for Cloudflare WARP with the parameters the WARP peer requires, and `vpn://` links for the Amnezia client;
- offers route and DNS presets, mobile and router modes, and custom CPS packet chains;
- ships with invariant tests, CI that publishes a Docker image, and automatic blue/green deploys to a VPS.

### Android TV ADB Control Center

Windows desktop GUI for Android TV / Google TV ADB pairing, wireless connection, scrcpy launch, APK installation, screenshots, remote control, shell commands, and diagnostics.

**Status:** desktop utility with release build  
**Links:** [repository](https://github.com/HereIamGosu/android-tv-adb-control-center) · [releases](https://github.com/HereIamGosu/android-tv-adb-control-center/releases)

What it does:

- pairs and connects Android TV / Google TV devices over ADB;
- launches scrcpy and common device actions from a Windows GUI;
- provides readable diagnostics instead of raw command-line noise.
