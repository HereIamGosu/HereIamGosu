### Android TV ADB Control Center

Windows desktop GUI for Android TV / Google TV ADB pairing, wireless connection, scrcpy launch, APK installation, screenshots, remote control, shell commands, and diagnostics.

  <a href="https://github.com/HereIamGosu/android-tv-adb-control-center">

  <a href="https://github.com/HereIamGosu/android-tv-adb-control-center">

    <img alt="Release" src="https://img.shields.io/github/v/release/HereIamGosu/android-tv-adb-control-center">
  </a>
</p>

**Stack:** Python, PySide6, ADB, scrcpy, Windows  
**Status:** desktop utility with release build  
**Links:** [repository](https://github.com/HereIamGosu/android-tv-adb-control-center) · [releases](https://github.com/HereIamGosu/android-tv-adb-control-center/releases)

What it does:

- pairs and connects Android TV / Google TV devices over ADB;
- launches scrcpy and common device actions from a Windows GUI;
- provides readable diagnostics instead of raw command-line noise.
